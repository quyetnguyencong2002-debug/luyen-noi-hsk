# Luyện Nói HSK

App luyện nói tiếng Trung (HSK 1–5) cho người Việt, chạy trên trình duyệt điện thoại:

- **Giữ micro để nói**: chấm từng chữ (âm đầu, vần, điểm chính xác, trôi chảy, đầy đủ) bằng Azure Pronunciation Assessment (key gói Free của người dùng, chỉ lưu trên máy).
- **Đường thanh điệu**: so giọng người học với giọng mẫu, tính ngay trên máy.
- **Hội thoại theo 11 tình huống công việc** (HSK 1), mỗi lượt có 3 cách trả lời: đơn giản, tự nhiên, theo phong cách cá nhân.
- **Luyện từ & câu** theo 233 bài HSK 3.0, có giọng mẫu.

Mở trang → Cài đặt → dán key Azure Speech (Free F0) để chấm từng âm. Không có key thì app chỉ chấm thanh điệu.
